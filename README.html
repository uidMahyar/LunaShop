فروشگاه‌ساز (نسخه‌ی خام) — راهنمای سریع

۱) اجرا

  1. نرم‌افزار Node.js (نسخه‌ی ۱۸ یا بالاتر؛ بهتر است نسخه‌ی LTS) را از nodejs.org نصب کنید. هیچ بسته‌ی دیگری لازم نیست (npm install ندارد).
  2. ویندوز: روی start.bat دوبار کلیک کنید. لینوکس/مک: node server.js
  3. سایت: http://localhost:3000 — پنل مدیریت: http://localhost:3000/admin
  4. برای دیدن سایت روی گوشی (همان شبکه‌ی وای‌فای)، آدرس‌هایی که در پنجره‌ی اجرا چاپ می‌شود را باز کنید.

ورود اول: نام کاربری admin و رمز تصادفی اولیه در پنجره‌ی اجرا و فایل data/FIRST_LOGIN.txt نوشته می‌شود. بار اول، پنل از شما رمز جدید می‌خواهد.

۲) سیستم «کد» — تغییر نام‌ها

هر نام و متن سایت یک کد عددی دارد: مثلاً کد ۱ = نام سایت، کد ۲ = شعار، کد ۱۰۱ تا ۱۰۸ = نام دسته‌های پیش‌فرض و ... برای عوض کردن:

  • پنل ← کدها (متن‌ها) ← مقدار را تغییر دهید ← ذخیره.
  • بالای پنل دکمه‌ی «سایت با کدها»: سایت را باز می‌کند و روی هر متن، شماره‌ی کدش را نشان می‌دهد (فقط برای مدیر). با دکمه‌ی قرمز پایین صفحه خاموش می‌شود.
  • پنل ← ابزارها ← اعمال گروهی: هر خط یک تغییر، مثل 1 = نام جدید. همین خط‌ها را می‌توانید از چت بگیرید.
  • کادر «برو به کد…» بالای پنل: شماره را بنویسید و Enter بزنید.

نام دسته‌ها، محصولات، بنرها، صفحات، آیتم‌های منو و روش‌های ارسال هم کد دارند؛ هر موردی که بعداً بسازید خودکار کد بعدی را می‌گیرد.

۴) فونت (اختیاری ولی توصیه‌شده)

فایل Vazirmatn.woff2 را (فونت آزاد وزیرمتن) دانلود کنید و در پوشه‌ی public/fonts/ بگذارید. بدون آن، فونت پیش‌فرض سیستم (Tahoma) استفاده می‌شود.

۵) انتشار روی سرور (VPS)

PORT=3000 HOST=0.0.0.0 TRUST_PROXY=1 node server.js
# اجرای دائمی:  npm i -g pm2  &&  pm2 start server.js --name shop
  • جلوی برنامه یک وب‌سرور (Nginx یا Caddy) با HTTPS بگذارید و TRUST_PROXY=1 را فعال کنید.
  • DATA_DIR: مسیر پوشه‌ی داده (پیش‌فرض data/ کنار برنامه).
  • پشتیبان‌گیری: پوشه‌ی data را کامل کپی کنید (دیتابیس + تصویرها). هر روز یک نسخه‌ی خودکار در data/backups ساخته می‌شود.

۶) امنیت

  • رمزها با scrypt ذخیره می‌شوند؛ ورود با محدودیت تعداد تلاش؛ متن‌های ورودی پاک‌سازی می‌شوند؛ مبلغ و موجودی همیشه سمت سرور محاسبه می‌شود.
  • روی اینترنت حتماً از HTTPS استفاده کنید و رمز مدیر را قوی نگه دارید.

۷) هنوز در این نسخه نیست

درگاه پرداخت آنلاین، ورود مشتری با پیامک (OTP) و پنل کاربری مشتری، ارسال پیامک/ایمیل سفارش، نماد اعتماد. ساختار برای افزودن این‌ها آماده است (فاز بعد).

۸) ساختار فایل‌ها

server.js          سرور، مسیرها، API
lib/               دیتابیس، منطق فروشگاه، قالب‌های سایت، تعریف بخش‌های پنل، داده‌ی پیش‌فرض (seed.js)
public/            استایل و اسکریپت سایت، پنل مدیریت (public/admin)
data/              (خودکار ساخته می‌شود) db.json ، uploads ، backups
