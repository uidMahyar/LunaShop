انتشار فروشگاه روی GitHub Pages

۱) محصولات را روی کامپیوتر خودتان وارد کنید

مثل قبل start.bat را اجرا کنید و در http://localhost:3000/admin محصول، دسته و تنظیمات را بسازید. حتماً در پنل ← تنظیمات، راه‌های ارتباطی (واتس‌اپ، تلگرام، ایتا، ایمیل، تلفن) را پر کنید؛ سفارش‌ها از همین راه‌ها به دست شما می‌رسد.

۲) خروجی استاتیک بگیرید

روی build-static.bat دوبار کلیک کنید (یا node build-static.js). پوشه‌ی docs ساخته می‌شود.

اگر آدرس سایت شما به شکل user.github.io/نام-مخزن است، مسیر پایه را بدهید:

node build-static.js --base=/نام-مخزن --site=https://user.github.io/نام-مخزن

برای آدرس user.github.io یا دامنه‌ی شخصی لازم نیست. این مقادیر را می‌توانید یک‌بار در static.config.json هم بنویسید.

۳) روی GitHub بگذارید

پروژه را در یک مخزن بارگذاری کنید (پوشه‌ی data در .gitignore است و آپلود نمی‌شود)، سپس Settings ← Pages ← Branch: main و پوشه‌ی /docs.

هر بار که چیزی را در پنل عوض کردید، دوباره مرحله‌ی ۲ را اجرا کنید و پوشه‌ی docs را دوباره بفرستید.

۴) فونت

فایل Vazirmatn.woff2 را در public/fonts/ بگذارید، قبل از ساخت خروجی.

رفتار سفارش و محدودیت‌ها

  • سفارش در مرورگر مشتری ثبت می‌شود و مشتری باید متن آن را با دکمه‌ی واتس‌اپ/تلگرام/ایتا/ایمیل برای شما بفرستد. هیچ سفارشی به‌طور خودکار به سرور نمی‌رسد.
  • پنل مدیریت و وضعیت سفارش در سایت منتشرشده وجود ندارد. پیگیری سفارش از طریق پیام انجام می‌شود.
  • موجودی فقط در لحظه‌ی ساخت خروجی ثبت می‌شود و با فروش کم نمی‌شود. تعداد دفعات استفاده از کد تخفیف هم محدود نمی‌شود (کدها در فایل داده‌ی عمومی به‌صورت رمزشده هستند، ولی با حدس زدن قابل امتحان‌اند).
  • قیمت‌ها سمت مرورگر محاسبه می‌شود؛ پس قیمت نهایی را هنگام تأیید سفارش خودتان بررسی کنید.
